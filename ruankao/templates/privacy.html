隐私政策

说人话版：我们只收你的邮箱，只用来发报名提醒，不卖给任何人，你随时可以删掉。

一、我们收集什么

邮箱地址 必填
提交时的 IP 散列值 用于反滥用
你选择的报考地区 必填
订阅与发送记录 用于排障

我们不收集你的姓名、身份证号、手机号、密码、位置或设备信息。 IP 地址经单向散列后存储，无法还原成原始地址，仅用于识别批量滥用。

二、用来做什么

只用于向你发送软考报名相关提醒（报名时间公布、报名开放、报名截止前、缴费截止前）， 以及订阅本身所必需的操作邮件（确认订阅、退订确认）。 我们不会用这个邮箱做营销、不会与其他数据做关联分析、不会用于任何其他目的。

三、给不给别人

不。我们不会把邮箱地址出售、出租或提供给任何第三方。 唯一的例外是发送邮件所必需的服务商——它们仅作为受托处理者接触这些数据， 且只用于投递邮件这一个用途。

四、保存多久

在你保持订阅期间持续保存。你退订后，记录会保留但不再用于发送； 你选择「彻底删除」后，邮箱地址与订阅记录会立即从数据库中移除，无法恢复。

五、你的权利

查阅与更正管理页链接
暂停收取提醒管理页一键操作
退订每封邮件底部
彻底删除管理页一键操作

以上全部自助完成，不需要联系任何人。管理页链接在每封提醒邮件的底部。 {% if settings.site_contact_email %} 如遇问题可邮件联系 {{ settings.site_contact_email }}。 {% endif %}

六、怎么保护

传输过程使用 HTTPS 加密；管理页仅凭一封邮件里独有的随机链接访问，不设可被撞库的密码； 数据库访问权限受限。如果发生数据泄露，我们会在发现后尽快通过站内公告与邮件告知你。

七、政策变更

本政策如有实质性变更，我们会在此页面更新并注明生效日期，必要时通过邮件通知订阅者。

本项目是开源的，数据处理逻辑你可以直接在代码里核对。
